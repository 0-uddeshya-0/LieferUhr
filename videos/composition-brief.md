# Hyperframes Composition Brief: Lieferuhr 6-product launch series

## Objective

Six launch-style spots, one per product, generated by `videos/generate.py`
into `videos/compositions/*.html`, rendered to `videos/renderings/*.mp4`,
embedded on the landing page. This file is the contract; `brag-plan.md`
carries copy and storyboard.

## Output

- Compositions: `compositions/{einkauf,frachtradar,frachtamt,pruefamt,einsatzamt,postamt}.html`
- Format: landscape 1280×720, ~23.6s each
- Root composition `index.html` stays the brand opener.

## Source material

- UI screenshots in `assets/*.png` (real app captures, 1280×720;
  `fleet-dispatch.png` 1920×1200, `fleet-driver.png` 390×700).
- Product marks: `GLYPHS` map in generate.py on accent tiles.
- Copy: verbatim from `brag-plan.md` — German, no generic SaaS language.

## Creative direction

- Tone `polished` × `app-store`: hard cuts on beats, fast entrances
  (0.3–0.6s), settled holds for every readable line.
- UI shots are full-bleed with camera push/pan (`transform-origin` at the
  focal region), a traveling cursor with click ripple, an accent
  spotlight ring on the key region, and a lower-third caption pill whose
  text swaps mid-scene. Never a static screenshot.
- Hook scene is dark ink with word-by-word slam + accent underline sweep —
  contrast cut into the light product scenes.
- End card: accent wash, mark + name + "Demo testen" pill, umbrella tag.

## Beat map (cue preset `happy-beats-business-moves-vol-1`, 120 BPM)

- Reveal mark punch — beat-locked @ 3.02s
- Flow A enter @ 5.03s, cursor click @ 7.02s
- Flow B enter @ 10.52s, cursor click @ 13.01s
- Feature chips — beat-grid @ 16.02 / 16.52 / 17.02 (strong cues)
- End card enter — beat-locked @ 19.02s (strong cue)

## Audio

- `assets/music/happy-beats.mp3` — data-start 0, volume ~0.32, duration = comp.
- SFX (`assets/sfx/`): `impact-light.ogg` @ hook slam + reveal,
  `click.ogg` @ each cursor click, `tick.ogg` @ each chip, `select.ogg` @
  end card. All as `<audio data-start>` elements.

## Hyperframes requirements

- One paused root timeline per composition on `window.__timelines[id]`.
- Timed scenes as `class="clip"` with `data-start`/`data-duration`.
- No `Date.now`/`Math.random`; transforms only (`x/y/scale/rotation/
  opacity`); no `display`/`visibility` tweens; `.clip` untouched by tweens
  (animate inner wrappers).
- `npm run check` must pass before render.
